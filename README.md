**Roccaforte Strategica - Archetypes Edition** is a browser-based worker placement and strategy board game developed with HTML5, CSS3, Lucide Icons, and Vanilla JavaScript.

### 🎮 Game Features
- **Worker Placement Mechanics:** Strategic allocation of limited workers across various functional board spaces.
- **Dynamic Event System:** Random events each round (e.g., Famine, Imminent War, Black Market, Sun, Clouds) that alter prices, rewards, and available action spaces.
- **Archetype AI Opponents:** Autonomous bots with distinct strategic personalities (General, Merchant, Architect).
- **Stronghold & Military Scoring:** Station troops inside the Stronghold or keep them active for end-game majority and tactical bonuses.
- **Responsive Web Design:** Fully optimized interface for both mobile and desktop screens.

---

### 📁 Project Structure
The repository is organized into a modular structure:
- `index.html` — The main HTML document containing the core game layout and UI elements.
- `style.css` — Custom stylesheet containing rules, animations, and game board design.
- `*.js` — JavaScript modular files managing game logic, AI behaviors, event systems, and UI updates.
- `LICENSE` — Terms, conditions, and copyright declaration.

---

### 🚀 Getting Started
1. Clone or download the repository to your local computer.
2. Ensure the `LICENSE` file remains in the root directory alongside `index.html`.
3. Open `index.html` in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari). No compilation or external server setup is required.

### 🎮 Caratteristiche del Gioco
- **Meccanica di Piazzamento Lavoratori:** Gestione tattica delle risorse e posizionamento dei lavoratori su spazi azione dedicati.
- **Sistema di Eventi Dinamici:** Eventi casuali per ogni round (Carestia, Guerra Imminente, Mercato Nero, Sole, Nuvole) che modificano costi, rendimenti e disponibilità dei luoghi.
- **Avversari Virtuali con Archetipi:** Bot dotati di IA differenziata in base al ruolo (Generale, Mercante, Architetto).
- **Controllo e Punteggio Roccaforte:** Deposito e tracciamento delle truppe nella Roccaforte per ottenere maggioranze e punti vittoria a fine partita.
- **Interfaccia Responsive:** Design flessibile e ottimizzato sia per dispositivi mobili che per desktop.
